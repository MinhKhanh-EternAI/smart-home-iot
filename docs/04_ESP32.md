# 4. ESP32 Assistant — Hiện Trạng & Kế Hoạch

## Hiện trạng

**Dự án PlatformIO**: `esp32-assistant/`
**Board**: `esp32dev`
**Framework**: Arduino

### PlatformIO Dependencies
```
mobizt/Firebase Arduino Client Library for ESP8266 and ESP32 @ ^4.4.14
adafruit/Adafruit SSD1306 @ ^2.5.10
adafruit/Adafruit GFX Library @ ^1.11.9
earlephilhower/ESP8266Audio @ ^1.9.7
```

### Code hiện tại (`src/main.cpp`)
```cpp
#include <Arduino.h>

int myFunction(int, int);

void setup() {
  int result = myFunction(2, 3);
}

void loop() { }

int myFunction(int x, int y) { return x + y; }
```

⚠️ **ESP32 hiện tại CHƯA có code thực tế** — chỉ là template rỗng.

## Các thư viện đã cài sẵn (gợi ý tính năng)

| Thư viện | Phiên bản | Gợi ý mục đích |
|-----------|-----------|-----------------|
| Firebase ESP Client | ^4.4.14 | Kết nối Firebase giống ESP8266 |
| Adafruit SSD1306 | ^2.5.10 | Màn hình OLED I2C |
| Adafruit GFX | ^1.11.9 | Đồ họa cho OLED |
| ESP8266Audio | ^1.9.7 | Phát âm thanh (MP3) |

## Gợi ý phát triển

### 1. Màn hình OLED I2C hiển thị thông tin
Hiển thị nhiệt độ, độ ẩm, trạng thái thiết bị từ Firebase.

### 2. Phát âm thanh / giọng nói
Dùng `ESP8266Audio` để phát thông báo giọng nói khi có người quẹt thẻ, báo động, hoặc nhắc lịch trình.

### 3. Cảm biến bổ sung
- DHT22 (chính xác hơn DHT11)
- Cảm biến khói/gas MQ-2
- Cảm biến ánh sáng BH1750

### 4. Giao tiếp UART với ESP8266
ESP32 và ESP8266 có thể giao tiếp qua Serial (UART) để chia sẻ dữ liệu cảm biến.

### 5. Kết nối WiFi dự phòng
ESP32 làm hotspot dự phòng nếu ESP8266 mất kết nối.

## Lưu ý khi code ESP32

- Dùng chung **Firebase project** với ESP8266 (cùng `FIREBASE_HOST`, `FIREBASE_API_KEY`)
- I2C pins mặc định ESP32: SDA=GPIO21, SCL=GPIO22
- Có thể dùng chung Firebase stream hoặc node riêng `/esp32/...`
