# 4. ESP32 — Voice AI Assistant (Xiaozhi + MCP)

## Tổng quan

ESP32 hoạt động như một **Voice AI Assistant**, chạy firmware Xiaozhi (MCP-based chatbot)
kết nối cloud LLM (Qwen/DeepSeek) với mic, loa, màn hình OLED.

---

## Sơ đồ chân kết nối

### OLED SSD1306 (I2C)

| OLED | ESP32 GPIO |
|------|------------|
| GND  | GND        |
| VDD  | 3.3V       |
| SCK  | GPIO22     |
| SDA  | GPIO21     |

### INMP441 (Mic I2S)

| INMP441 | ESP32 GPIO |
|---------|------------|
| SD      | GPIO32     |
| WS      | GPIO27     |
| SCK     | GPIO26     |
| LR      | GND        |
| VDD     | 3.3V       |
| GND     | GND        |

### MAX98357 (Amp I2S)

| MAX98357 | ESP32 GPIO |
|----------|------------|
| DIN      | GPIO25     |
| BCLK     | GPIO26     |
| LRC      | GPIO27     |
| SD       | 3.3V       |
| VIN      | 5V         |
| GND      | GND        |

### Lưu ý I2S bus
- **GPIO26** = BCLK (dùng chung mic + amp)
- **GPIO27** = WS/LRC (dùng chung mic + amp)
- **GPIO32** = mic SD (data từ mic → ESP32)
- **GPIO25** = amp DIN (data từ ESP32 → amp)

| Hạng mục | Trạng thái |
