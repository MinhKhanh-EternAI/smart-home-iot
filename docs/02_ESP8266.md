# 2. ESP8266 Core — Chi Tiết Phần Cứng

## Board: NodeMCU Lolin (CH340)

- **Platform**: `espressif8266` (PlatformIO)
- **Board**: `nodemcuv2`
- **Framework**: Arduino
- **Monitor Speed**: 115200 baud
- **Upload Speed**: 9600 baud
- **Upload Reset**: nodemcu

### PlatformIO Dependencies (`platformio.ini`)
```
mobizt/Firebase Arduino Client Library for ESP8266 and ESP32 @ ^4.4.14
miguelbalboa/MFRC522 @ ^1.4.11
marcoschwartz/LiquidCrystal_I2C @ ^1.1.4
adafruit/DHT sensor library @ ^1.4.6
adafruit/Adafruit Unified Sensor @ ^1.1.14
robtillaart/PCF8574 @ ^0.4.1
```

## Cấu hình chân GPIO (Config.h)

| ESP8266 | GPIO | Thiết bị | Giao thức | Ghi chú |
|---------|------|----------|-----------|---------|
| **D8** | GPIO15 | RC522 SDA (SS) | SPI | Pull-down sẵn → boot OK |
| **D5** | GPIO14 | RC522 SCK | SPI | |
| **D7** | GPIO13 | RC522 MOSI | SPI | |
| **D6** | GPIO12 | RC522 MISO | SPI | |
| **D0** | GPIO16 | RC522 RST | SPI | Reset RFID |
| **D2** | GPIO4 | SDA (LCD I2C + PCF8574) | I2C | Bus chung |
| **D1** | GPIO5 | SCL (LCD I2C + PCF8574) | I2C | Bus chung |
| **D3** | GPIO0 | DHT11 | Digital | Pull-up 4.7k-10k bắt buộc |
| **D4** | GPIO2 | Servo Cửa (Door) | PWM | An toàn, không dùng UART |

| **TX** | GPIO1 | *Không dùng* | — | |
| **A0** | ADC0 | Water Sensor | Analog | 0-3.3V, 0-1023 |

### Cấu hình GỐC (cũ — `USE_OPTIMIZED_PINS = 0`)

| ESP8266 | GPIO | Thiết bị |
|---------|------|----------|
| RX | GPIO3 | Servo Cửa |
| TX | GPIO1 | Servo Mái |
| D4 | GPIO2 | PIR |

## PCF8574 — Mạch mở rộng I/O

- **Địa chỉ I2C**: `0x20` (mặc định), cũng có thể là `0x27` hoặc `0x3F`
- **Điện áp**: 3.3V

| Chân PCF8574 | Pin Name | Thiết bị | Loại | Ghi chú |
|-------------|----------|----------|------|---------|
| **P0** | PCF_RELAY_OUTDOOR | Relay Đèn sân vườn | Output, Active Low | LED 12V |
| **P1** | PCF_RELAY_INDOOR | Relay Đèn trong nhà | Output, Active Low | LED 12V |
| **P2** | PCF_BUZZER | Còi chip (Buzzer) | Output, Active Low | 1 bíp / 3 bíp |
| **P3** | PCF_PIR_INPUT | Cảm biến PIR | Input | Chỉ dùng ở cấu hình TỐI ƯU |
| **P4** | PCF_FAN_RELAY | Relay Quạt | Output, Active Low | Động cơ DC 5V |
| **P5-P7** | — | Trống | — | Dự phòng |

## Thiết bị & Linh kiện

### 1. RFID RC522
- **Giao tiếp**: SPI
- **Tần số**: 13.56 MHz
- **Điện áp**: 3.3V (⚠️ **KHÔNG** cắm 5V — sẽ hỏng chip)
- **UID Format**: 8 ký tự Hex (ví dụ: `A1B2C3D4`)
- **Thư viện**: `MFRC522` (miguelbalboa)

### 2. DHT11
- **Chân**: D3 (GPIO0)
- **Điện áp**: 3.3V
- **Cảnh báo**: Cần trở pull-up 4.7k-10k lên 3.3V. GPIO0 phải ở mức HIGH khi boot.
- **Interval**: Đọc mỗi 10 giây
- **Threshold**: Cập nhật Firebase khi nhiệt độ thay đổi >=0.5°C hoặc độ ẩm >=1%
- **An toàn**: Cảnh báo nếu nhiệt độ >=50°C

### 3. Water Sensor (Cảm biến mưa)
- **Chân**: A0 (ADC)
- **Điện áp**: 3.3V (từ ESP8266)
- **Ngưỡng**: `< 500` = có mưa (điện trở giảm khi ướt)
- **Interval**: Đọc mỗi 3 giây (trong RoofController)
- **Tự động hóa**: Đóng mái che khi mưa, mở khi tạnh

### 4. PIR (Cảm biến chuyển động)
- **Cấu hình TỐI ƯU**: PCF8574 P3
- **Cấu hình GỐC**: D4 (GPIO2)
- **Tự động**: Bật đèn sân vườn khi phát hiện người, tắt sau 30s không chuyển động

### 5. Servo MG90S
| | Cấu hình TỐI ƯU | Cấu hình GỐC |
|---|---|---|
| **Servo Cửa** | D4 (GPIO2) ✅ ổn định | RX (GPIO3) ⚠️ rung khi boot/nạp code |
| **Servo Mái** | RX (GPIO3) — sau Serial.end() | TX (GPIO1) ⚠️ debug bootloader |

- **Góc mở**: 90°
- **Góc đóng**: 0°
- **Cảnh báo**: Chân RX/TX bị ảnh hưởng bởi UART bootloader. Giải pháp: `Serial.end()` trước `Servo.attach()`.

### 6. LCD I2C 16x2
- **Địa chỉ**: Auto-detect `0x27` → `0x3F` → `0x20`
- **Điện áp**: 5V (cấp nguồn) / Tín hiệu I2C 3.3V từ ESP8266 (tương thích)
- **Bus**: I2C chung với PCF8574 (D2=SDA, D1=SCL)
- **Chức năng**: Hiển thị trạng thái WiFi, Access GRANTED/DENIED, thông báo hệ thống

### 7. Relay Module
- **Loại**: Active Low (kích ở mức LOW)
- **Điện áp**: 5V (cấp coil) / Tín hiệu 3.3V từ PCF8574 (tương thích)
- **writeRelay(pin, turnOn)**: `turnOn=true → pcf.write(pin, LOW)` (bật), `turnOn=false → pcf.write(pin, HIGH)` (tắt)

### 8. Buzzer (Còi chip)
- **Chân**: PCF8574 P2
- **1 bíp ngắn**: Access GRANTED (cửa mở thành công)
- **3 bíp dồn dập**: Access DENIED (thẻ không hợp lệ)

## Sơ đồ nguồn

```
Nguồn 12V DC
    ├── LED 12V Outdoor
    ├── LED 12V Indoor
    └── LM2596 (Buck Converter → 5V)
         ├── Servo Door 5V
         ├── Servo Roof 5V
         ├── Relay Module 5V
         ├── LCD I2C 5V
         ├── PIR 5V
         └── Buzzer 5V
              └── ESP8266 NodeMCU (USB 5V / Vin → 3.3V internal)
                   ├── RC522 3.3V
                   ├── DHT11 3.3V
                   ├── Water Sensor 3.3V
                   └── PCF8574 3.3V
```

⚠️ **Bắt buộc chung GND**: Tất cả GND (12V, 5V, ESP8266) phải nối chung.
